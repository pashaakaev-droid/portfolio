Аналитический дашборд туристических потоков

Мостуризм / RUSSPASS

В рамках проекта разрабатывался аналитический дашборд для внутреннего портала RUSSPASS, предназначенный для анализа туристических потоков и динамики туристических показателей. Решение позволяло изучать распределение туристов из России, стран ближнего и дальнего зарубежья.

Цель проекта

Создать инструмент для анализа туристической статистики, позволяющий отслеживать динамику туристических потоков, сравнивать показатели по различным категориям туристов и оценивать изменения туристической активности.

Роль в проекте

BI-аналитик / BI-разработчик

Отвечал за разработку аналитического дашборда из двух страниц: от проработки структуры и настройки визуализаций до адаптации интерфейса под разные устройства, тестирования и последующей поддержки решения.

Результаты

• Разработан аналитический дашборд из двух страниц для внутреннего портала RUSSPASS.

• Реализовано отображение туристических показателей и динамики по основным категориям туристов.

• Создан интерфейс для анализа туристических потоков из России, стран ближнего и дальнего зарубежья.

• Обеспечена адаптация дашборда для компьютеров, планшетов и мобильных устройств с использованием CSS Grid и медиазапросов.

• Подготовленное решение передано для использования в рамках проекта.
