Система мониторинга показателей

ДИТ

В рамках проекта разрабатывалась система интерактивных BI-дашбордов для мониторинга ключевых показателей в интересах высшего руководства ДИТ. Решение обеспечивало оперативный доступ к аналитической информации с обновлением данных каждые 3 минуты.

Цель проекта

Создать единую систему интерактивных дашбордов для оперативного мониторинга показателей и анализа данных с возможностью детализации и гибкой фильтрации.

Роль в проекте

BI-аналитик / BI-разработчик

Отвечал за разработку пяти дашбордов: от реализации визуализаций и пользовательской логики до тестирования, оптимизации и передачи готовых решений заказчику.

Зона ответственности

Разработка дашбордов

Insight BI

• Разработка пяти дашбордов с нуля
• Проектирование структуры страниц и расположения визуализаций
• Реализация единой системы дизайна
• Доработка интерфейсов при изменении требований

Интерактивность и кастомизация

CSS / JavaScript / HTML

• Реализация глобальных и локальных фильтров, кросс-фильтрации
• Настройка drill-down и переходов на детализированные страницы
• Разработка всплывающих окон и пользовательских сценариев
• Кастомизация стандартных BI-компонентов и обход ограничений платформы

Работа с данными

Dremio / SQL

• Разработка запросов к готовым витринам данных
• Настройка источников для BI-компонентов
• Реализация и корректировка логики расчёта метрик
• Проверка корректности данных и выявление ошибок в расчётах

Оптимизация и тестирование

• Рефакторинг BI-компонентов и оптимизация производительности
• Сокращение количества запросов к витринам данных
• Выявление проблем загрузки и ошибок обработки данных
• Адаптация компонентов под реальные объёмы данных

Взаимодействие с командой

• Получение и проработка требований от бизнес-аналитика
• Подготовка технических заданий для системных аналитиков и дата-инженеров
• Обсуждение технической реализации с frontend-разработчиками
• Тестирование доработок и согласование результатов

Результаты

• Разработаны и переданы заказчику пять интерактивных BI-дашбордов для мониторинга показателей.

• Реализованы сложные сценарии фильтрации, детализации данных и навигации между аналитическими страницами.

• Обеспечено обновление данных с интервалом около 3 минут.

• Оптимизирована работа BI-компонентов за счёт рефакторинга и сокращения количества запросов к источникам данных.

• Последний дашборд разработан в сжатые сроки — за 3 дня после получения готовых витрин данных.

• Все пять дашбордов успешно завершены и переданы заказчику.
